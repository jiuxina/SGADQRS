## 重新生成 / 更新截图

```bash
cd docs/defense-ppt
node gen_ppt.js          # 改 gen_ppt.js 后重新生成
python qa.py 赛友TeamUp-答辩PPT.pptx   # 结构检查（越界/溢出/重叠）
```

截图在 `shots/`（01 登录页、02 学生竞赛列表、03 招募广场、04 管理员数据统计）。
系统运行中重新截图后直接 `node gen_ppt.js` 即可替换（第 12 页自动读取 `shots/`）。
