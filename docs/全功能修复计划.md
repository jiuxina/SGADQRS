## SCMS 全功能修复计划

学生竞赛信息管理系统 — 9 项严重缺失 + 12 项重要缺失 + 10 项体验优化 + 6 项通用技术改进

---

### P0 严重缺失（9 项）

#### 1. 教师端 — 成绩录入入口

- 当前问题：后端 save() 和前端 resultApi.save() 已实现，UI 无新增入口
- 改动文件：`frontend/src/pages/TeacherGrades.tsx`、`frontend/src/components/EditGradeDialog.tsx`
- 具体内容：
  - 在成绩页顶部添加"新增成绩"按钮
  - 弹窗表单包含：选择学生/团队、分数、排名、奖项等级、奖项名称、备注
  - 调用 resultApi.save() 提交
- 预计工作量：中

#### 2. 教师端 — 竞赛编辑功能

- 当前问题：后端 update 接口和前端 competitionApi.update() 已就绪，无编辑 UI
- 改动文件：`frontend/src/pages/TeacherCompetitions.tsx`、`frontend/src/pages/TeacherCompetitionCreate.tsx`（复用为编辑模式）
- 具体内容：
  - TeacherCompetitionCreate 支持通过路由参数 id 加载已有竞赛数据进入编辑模式
  - 新增路由 `/teacher/competitions/:id/edit`
  - 竞赛列表操作列增加"编辑"按钮
  - 草稿和被驳回状态的竞赛可编辑并提交审核
- 预计工作量：大

#### 3. 学生端 — 团队管理页面

- 当前问题：后端 createTeam/joinTeam/teamList 已实现，前端 API 已封装，无页面
- 改动文件：新建 `frontend/src/pages/StudentTeams.tsx`、`frontend/src/App.tsx`、`frontend/src/components/DesktopLayout.tsx`
- 具体内容：
  - 新建学生团队管理页面：查看我的团队列表、创建团队（队名+口号）、通过团队 ID 加入团队
  - 添加路由 `/student/teams`
  - 侧边栏 student navItems 增加"我的团队"入口
  - 展示团队成员列表和团队状态
- 预计工作量：大

#### 4. 管理员端 — 成绩管理和报名监管页面

- 当前问题：后端已授权 ADMIN，前端 API 已封装，无页面
- 改动文件：新建 `frontend/src/pages/AdminGrades.tsx` 和 `frontend/src/pages/AdminRegistrations.tsx`、`frontend/src/App.tsx`、`frontend/src/components/DesktopLayout.tsx`
- 具体内容：
  - AdminGrades：按竞赛查看所有成绩，支持按奖项等级筛选，可发布/撤销发布
  - AdminRegistrations：按竞赛查看所有报名记录，支持按状态筛选，可审核
  - 添加路由 `/admin/grades` 和 `/admin/registrations`
  - 侧边栏 admin navItems 增加两个入口
- 预计工作量：大

#### 5. 教师端 — 附件管理 UI

- 当前问题：后端 addAttachment/deleteAttachment 和前端 API 已就绪，无 UI 入口
- 改动文件：`frontend/src/pages/TeacherCompetitionCreate.tsx`（编辑模式下）或 `frontend/src/pages/TeacherCompetitions.tsx`（管理弹窗内）
- 具体内容：
  - 在竞赛编辑页或管理弹窗中增加附件上传区域
  - 支持多文件上传，调用 fileApi.upload 获取元数据后调用 competitionApi.addAttachment 关联
  - 展示已上传附件列表，支持删除
- 预计工作量：中

#### 6. 管理员端 — 用户创建/删除/禁用/重置密码

- 当前问题：后端 CRUD 已实现，前端 userApi.create/delete 已定义，页面缺失
- 改动文件：`frontend/src/pages/AdminUsers.tsx`、`backend/src/main/java/com/scms/entity/User.java`（加 status 字段）、`backend/sql/init.sql`
- 具体内容：
  - User 实体和数据库表新增 status 字段（0-禁用 1-正常）
  - 页面增加"新增用户"按钮和创建表单（用户名、密码、姓名、角色、院系级联）
  - 操作列增加"删除""禁用/启用"按钮
  - 编辑弹窗增加"重置密码"入口
  - 编辑弹窗增加角色变更（userType 下拉框）
  - 后端补充 disableUser 接口
- 预计工作量：大

#### 7. 管理员端 — 组织架构 CRUD

- 当前问题：AdminOrgTree 纯只读，后端 DeptController 只有 GET
- 改动文件：`backend/src/main/java/com/scms/controller/DeptController.java`、`backend/src/main/java/com/scms/service/SystemService.java`、`frontend/src/pages/AdminOrgTree.tsx`
- 具体内容：
  - 后端新增 POST/PUT/DELETE 接口用于院系、专业、班级的增删改
  - 前端树形节点增加"新增子项""编辑""删除"操作按钮
  - 编辑弹窗支持名称、编码、排序等字段
  - 删除前检查是否有关联数据（如院系下有专业则不允许删除）
- 预计工作量：大

#### 8. 三角色 — 消息发送功能

- 当前问题：只能被动接收系统消息，无法主动发送
- 改动文件：`backend/src/main/java/com/scms/controller/MessageController.java`、`backend/src/main/java/com/scms/service/SystemService.java`、新建 `frontend/src/pages/MessageCompose.tsx` 或内嵌写信组件、各角色消息页面
- 具体内容：
  - 后端新增 `POST /message/send` 接口，支持指定接收人（按用户/按角色/按院系）
  - 前端各角色消息页增加"发消息"按钮
  - 写信表单：接收人选择、标题、内容
  - 管理员可群发通知
- 预计工作量：大

#### 9. 学生端 — 报名与团队功能对接

- 当前问题：报名不传 teamId，团队报名流程断裂
- 改动文件：`frontend/src/pages/StudentCompetitions.tsx`
- 具体内容：
  - 报名弹窗增加"以团队身份报名"选项
  - 选择后展示"我的团队"下拉列表（调用 teamList API）
  - 将选中的 teamId 传入 registrationApi.register
  - 团队报名时自动为团队所有成员创建报名记录（或仅队长代表报名）
- 预计工作量：中

### 实施建议

按阶段分批推进，每阶段可独立交付：

**第一阶段（核心修复）**：第 1-9 项，预计 5-7 天
**第二阶段（业务完善）**：第 10-21 项，预计 5-7 天
**第三阶段（体验优化）**：第 22-31 项，预计 3-5 天
**第四阶段（技术债务）**：第 32-37 项，预计 3-5 天

总计约 16-24 天工作量。建议优先完成第一阶段，因为大部分 P0 项只需前端对接已有后端接口，改动范围可控。
