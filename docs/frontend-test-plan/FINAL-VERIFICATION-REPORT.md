### 问题 1: 用户统计 API 调用失败

**严重程度**: ⚠️ 中等
**页面**: /admin/users
**描述**: 控制台显示 4 个错误："加载用户统计失败: Error: 服务器内部错误"
**影响**: 用户统计卡片可能无法正确显示数据
**建议**: 检查后端 /api/user/stats 接口是否正常

### 问题 2: 控制台错误

**严重程度**: ⚠️ 低
**页面**: 多个页面
**描述**: 控制台显示 4-6 个错误（主要与用户统计 API 相关）
**影响**: 不影响主要功能，但影响开发体验
**建议**: 修复 API 错误或优化错误处理
