# SCMS 前端功能验证计划

## 概述

**目标**: 验证学生竞赛信息管理系统 (SCMS) 前端所有页面和交互元素的可用性

**测试环境**:
- 前端地址: http://localhost:3000
- 后端地址: http://localhost:8080/api
- 浏览器: Chromium (via Playwright)

**测试账号**:
| 角色 | 账号 | 密码 |
|------|------|------|
| 管理员 | admin | 123456 |
| 教师 | T2024001 | 123456 |
| 学生 | S20210001 | 123456 |

---

## 验证维度

对于每个交互元素，我将从以下维度验证：

1. **点击什么**: 标识用户需要交互的元素（按钮、链接、输入框等）
2. **有什么用**: 解释该元素的功能目的
3. **预期出现什么**: 点击/交互后应该发生什么
4. **实际与预期相差多少**: 实际结果与预期的对比
